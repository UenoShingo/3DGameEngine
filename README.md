# VisualEngine

VisualEngine is a custom 3D game engine built with C++20, DirectX 12, and HLSL.

## Development Environment

- Visual Studio 2026
- C++20
- Windows x64
- Direct3D 12
- HLSL / DXC

## Project Goals

- Unreal Engine-inspired editor
- Actor / Component / World architecture
- Visual scripting (Blueprint-style)
- Node-based Shader Graph
- GPU particle and VFX Graph systems
- Physically Based Rendering
- Deferred Rendering
- Global Illumination
- Hardware Ray Tracing
- GPU-driven rendering
- Standalone Windows game builds

## Architecture

The project is planned around three components:

- Engine: rendering, scene, assets, and gameplay
- Editor: graphical authoring and debugging tools
- Game: standalone runtime application
