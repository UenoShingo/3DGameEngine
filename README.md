# MyGameEngine

DirectX 12 and C++20 based custom 3D game engine.

## Development Environment

- Visual Studio 2026
- C++20
- Direct3D 12
- CMake
- Windows SDK

## Architecture

- Engine: Core engine systems
- Editor: Game development editor
- Game: Sample game runtime

## Development Roadmap

- Phase 1: Core and DirectX 12
- Phase 2: 3D Rendering
- Phase 3: Scene Architecture
- Phase 4: Editor
- Phase 5: Asset Management
- Phase 6: Game Runtime
- Phase 7: Advanced Rendering
- Phase 8: Release
